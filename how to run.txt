AI Calling - Excel Lead
========================

This file explains how to run the full project end-to-end, with updated backend audio and Exotel configuration.

1. PREREQUISITES
----------------
- Node.js 18+ installed
- Python 3.10+ installed
- MongoDB running locally
- ngrok installed and running for public HTTPS webhook access
- `backend-node`, `ai-python`, `leads/`, `audio/` directories present

2. PROJECT STRUCTURE
--------------------
- `backend-node/` : Node.js backend and Exotel webhook/app server
- `ai-python/`   : Python AI engine and transcription service
- `audio/`       : WAV audio assets (including `greeting.wav` and `greeting_telephony.wav`)
- `leads/`       : Excel lead file(s)
- `recordings/`  : call recording output

3. SETUP MONGODB
----------------
Start MongoDB if not already running:

```bash
sudo systemctl start mongod
# or
mongod --dbpath /var/lib/mongodb
```

4. PREPARE AUDIO ASSETS
-----------------------
Ensure telephony WAV files exist in `audio/`.
The backend now uses `greeting_telephony.wav`.
If not present, run from `backend-node/`:

```bash
cd backend-node
npm install
node audio_optimizer.js
```

This generates telephony-compatible WAV files:
- `audio/greeting_telephony.wav`
- `audio/closing_telephony.wav`
- `audio/question_1_telephony.wav`
- `audio/question_2_telephony.wav`

5. START AN NGROK HTTPS TUNNEL
------------------------------
Run ngrok to expose your local backend publicly over HTTPS:

```bash
cd /run/media/ritesh/Project Data/AI Projects/AI Calling - Excel Lead/backend-node
ngrok http 3000
```

Use the HTTPS forwarding URL shown by ngrok.
In your screenshot, it is:

`https://gainfully-conjoined-aerobics.ngrok-free.dev`

6. UPDATE BACKEND ENVIRONMENT
-----------------------------
Edit `backend-node/.env` with the ngrok URL and audio file name.
Example entries:

```env
BASE_URL=https://gainfully-conjoined-aerobics.ngrok-free.dev
ALLOW_LOCAL_BASE_URL=true
AUDIO_FILE_NAME=greeting_telephony.wav
```

Also confirm these values in `backend-node/.env`:

```env
PORT=3000
MONGO_URI=mongodb://localhost:27017/ai_calling
AI_ENGINE_URL=http://localhost:8000
AUDIO_DIR=../audio
EXOTEL_BASE_URL=https://api.exotel.com/v1
```

7. START PYTHON AI ENGINE
-------------------------
From the root of the project:

```bash
cd ai-python
pip install -r requirements.txt
python main.py server
```

This starts the Python service on:
- `http://localhost:8000`

8. START NODE BACKEND
---------------------
From the backend folder:

```bash
cd backend-node
npm install
npm run dev
```

This starts the backend on:
- `http://localhost:3000`

9. VERIFY ENDPOINTS
-------------------
Use a browser or curl to verify these endpoints:

- `http://localhost:3000/health`
- `http://localhost:3000/test-audio`
- `https://gainfully-conjoined-aerobics.ngrok-free.dev/test-audio`
- `https://gainfully-conjoined-aerobics.ngrok-free.dev/audio/greeting_telephony.wav`
- `https://gainfully-conjoined-aerobics.ngrok-free.dev/voice-flow?campaignId=demo&leadId=demo`

10. EXOTEL / VOICE FLOW USAGE
----------------------------
In your Exotel outbound call settings, set:

- `Url` to:
  `https://gainfully-conjoined-aerobics.ngrok-free.dev/voice-flow?campaignId=<campaignId>&leadId=<leadId>`

- `StatusCallbackUrl` to:
  `https://gainfully-conjoined-aerobics.ngrok-free.dev/webhook/call-status`

- `RecordingCallbackUrl` already configured in backend voice XML by the call flow logic.

11. KEY BACKEND ROUTES
----------------------
- `GET /voice-flow` : returns Exotel XML pointing to the greeting WAV
- `GET /audio/:fileName` : serves telephony WAV files
- `GET /test-audio` : runs public URL + WAV compatibility diagnostics
- `POST /webhook/recording` : receives Exotel recording callbacks
- `POST /webhook/call-status` : receives Exotel call status callbacks

12. COMMON TROUBLESHOOTING
-------------------------
- If `test-audio` fails, check `BASE_URL` and ngrok status.
- If Exotel cannot fetch audio, ensure `https://<ngrok-url>/audio/greeting_telephony.wav` opens in a browser.
- If the backend crashes, run:

```bash
cd backend-node
node -c src/index.js
```

- If the Python engine fails, check `ai-python/main.py` and ensure `http://localhost:8000` is reachable.

13. OPTIONAL: PUBLIC URL update
--------------------------------
If ngrok changes, update `backend-node/.env` and restart backend.

14. FINAL CHECK
---------------
The required flow is:
1. Python AI server running
2. Node backend running
3. ngrok tunnel active
4. Exotel pointing to public `/voice-flow`
5. `greeting_telephony.wav` served over HTTPS
6. Recording + webhook flow working

If any step fails, restart that service and verify the corresponding URL.
