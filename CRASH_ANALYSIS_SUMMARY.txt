================================================================================
CRASH SCENARIOS IDENTIFIED
================================================================================

SCENARIO 1: "Call Connected Then Immediately Ends"
  - User hangs up after 1 second
  - runAutomationFlow() receives CancellationException
  - No try-catch to handle it
  - Service crashes
  - User sees app crash dialog

SCENARIO 2: "Network Glitch After 15 Reconnects"
  - WiFi drops, reconnects after 2 minutes
  - SocketManager tries 15 reconnects, gives up
  - App continues running but unresponsive
  - Backend never receives call state
  - Flow hangs indefinitely

SCENARIO 3: "Audio File Missing"
  - callAudioPlayer.getAudioFile() returns null
  - Code checks null but then calls socketManager?.sendCallState()
  - If socketManager is null, crashes with NullPointerException
  - Service crashes

SCENARIO 4: "Recording Permission Revoked"
  - User revokes RECORD_AUDIO permission in settings
  - Next call tries to record
  - RecordingManager throws SecurityException
  - Flow doesn't catch it
  - Service crashes

SCENARIO 5: "Rapid Start/Stop Calls"
  - User starts call, hangs up, starts another immediately
  - First call's finally block tries to release WakeLock
  - Second call hasn't called acquireWakeLock yet
  - WakeLock.release() throws IllegalArgumentException
  - Service crashes

SCENARIO 6: "Samsung Bluetooth SCO Lockup"
  - First call with Bluetooth headset
  - SCO lock doesn't release properly on Samsung
  - Second call tries to start SCO
  - RuntimeException thrown
  - Audio routing fails

SCENARIO 7: "Broadcast Receiver Not Registered"
  - Device rotates screen during MainActivity startup
  - registerReceiver() in progress
  - onDestroy() called
  - unregisterReceiver() called on receiver that was never registered
  - IllegalArgumentException thrown
  - Activity crashes

SCENARIO 8: "Malformed Backend JSON"
  - Backend sends incomplete JSON
  - JSONObject() throws JSONException
  - Listener thread crashes
  - WebSocket listener becomes unresponsive
  - No more backend messages received
